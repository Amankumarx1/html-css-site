# EAK International School — Web Application

> **Live Deployment:** [https://html-css-site-hazel.vercel.app](https://html-css-site-hazel.vercel.app)  
> **Tech Stack:** Pure Vanilla HTML5, CSS3, JavaScript (ES6+), Tailwind CSS v3 (JIT CDN)  
> **Design Language:** Architectural Monochrome with Liquid-Glass Interactions & Specular Highlights  

---

## 🌟 Highlights & Features

- **7 Interconnected Responsive Pages**:
  - `index.html`: Architectural hero with background video, metrics counters, educational pillars, facilities preview, testimonials, and dynamic admissions CTA.
  - `about.html`: Heritage timeline, mission & vision, leadership address by Principal Dr. Alistair Vance, and campus master plan.
  - `academics.html`: K-12 learning stages (Primary, Middle, Secondary, Senior Secondary) with curriculum breakdown.
  - `admissions.html`: Interactive tuition fee calculator, document checklist, age eligibility matrix, and admission inquiry form.
  - `facilities.html`: Interactive facility category filters (STEM, Sports, Creative, Infrastructure) and 360° virtual tour modal.
  - `events.html`: Filterable school events, circulars, sports championship calendar, and digital event pass generator.
  - `contact.html`: Campus location, department extensions, and verified inquiry system.

- **Theme Engine**:
  - Obsidian Dark (default) and Swiss Paper Light themes.
  - Zero-flash theme persistence using synchronous pre-render bootstrapping.
  - Smooth 320ms transition between color schemes.

- **Performance & Polish**:
  - Unified `requestAnimationFrame` scroll controller with state caching.
  - RAF cubic ease-out stat counters and throttled mouse spotlights.
  - Off-screen `content-visibility: auto` layout containment.
  - Battery/GPU-saving background video pausing via `IntersectionObserver`.
  - Non-blocking script execution (`defer`) and font preconnection.
